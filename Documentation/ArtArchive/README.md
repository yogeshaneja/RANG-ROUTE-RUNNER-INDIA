# Archived original illustrations

RajasthanBazaar.jpg and RajasthanHorizon.jpg were the earlier original generated illustrations. Their bytes and Unity metadata are preserved here for reference/restoration. They are outside Unity's Assets/Resources tree and are no longer build inputs. The game uses RajasthanHorizonReal.jpg instead; the current street scenery is native 3D geometry. Original source/licensing acknowledgements in ASSET_REGISTER.md still apply.
